# Template pack

A theme pack for [Administratum](https://github.com/Arylmera/Administratum): two themes to copy and make your own.

- `vault-pink/`: **Pink Vault**, a style of Vault 111 (Fallout). Its green turns pink, its blue plum. No art of its own.
- `workshop/`: **Workshop**, a small world of its own, with one sheet of art (the break-out room, copied from Ordo
  Machinum to start from).

## Install

From GitHub: in Administratum, Settings → Hall → **Added themes**, type this repository's `owner/repo`, *Install*,
then *Restart to apply*.

By hand: copy this folder into the app's `themes` folder, then quit and restart the app.

| OS | Folder |
|---|---|
| Linux | `~/.local/share/com.arylmera.administratum/themes/` |
| macOS | `~/Library/Application Support/com.arylmera.administratum/themes/` |
| Windows | `%APPDATA%\com.arylmera.administratum\themes\` |

Then pick *Fallout* → *Pink Vault*, or *Workshop*, in Settings → Hall.

## Make it yours

Rename the theme folders, edit their `theme.json`, put your name in `LICENSE`, and rewrite this README. The guide:
[Making a theme pack](https://github.com/Arylmera/Administratum/blob/main/docs/theme-packs.md).
