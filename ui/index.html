    Hall plan

    Open space: one hall, the rooms a west wing. Rooms: only rooms, round the Sanctum; each keeps its scribes, who doze at their desk and run their shells at the room's own computer, and the departments in no room share one more.

    Rooms

    A room groups every department whose sessions work in a folder matching its pattern, fenced, in rule order before the rest of the hall. Glob: **/git/Terra/** (any case, \ and / alike); re: before a regex, matched anywhere in the folder path written with / separators (re:git/terra$). The first matching rule wins; a temp folder stays in the break-out room.
