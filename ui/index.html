    World and lighting
    Where the sun is

    Auto lighting follows the sun here (south and west are negative). Empty: fixed hours.

    View and size

    Pixel size; the window decides how big the hall is.

    Hall plan

    Open space: one hall, the rooms a west wing. Rooms: only rooms, round the Sanctum, each with its own computer.

    Rooms

    A room gathers the departments whose sessions work in a folder matching its pattern. The first matching rule wins.

    Pattern syntax

    Glob: **/git/Terra/** (any case, \ and / alike). re: before a regex, matched anywhere in the folder path written with / separators (re:git/terra$). The departments in no room share one more; a temp folder stays in the break-out room.

    Scribes

    Off: a click brings the session's Orca terminal to the front; the card still opens for a petition, or when there is no terminal.

    Quiet hours

    Stuck sessions

    A running shell command is never stuck. Polling (BashOutput, sleep, watch) never counts as a loop.

    Token alert

    New tokens, cache reads left out. A count you choose: the app cannot see your subscription's quota. Empty: no alert.

    Notifications

    CI verdict

    Asks GitHub, through your own gh, whether a push passes its checks. Off: nothing is asked.

    Night Vigil

    At this time an armed vigil starts its two-minute countdown to shutdown, even if a session still works. Read when the vigil is armed. Empty: no deadline.

    About the day report

    When the vigil arms and when it fires, the report is written there as YYYY-MM-DD-administratum-day.md, replacing that day's file. An absolute folder that exists; it is never created.
